# Sanchia Hair — Editorial Layout Reset Brief

## What Sanchia is trying to explain

The current page is not wrong because of one colour or one box. The problem is the overall layout rhythm.

It feels too boxy, too grid-like and not cohesive. The pictures sit in boxes, then the writing sits underneath or beside them, but the whole section does not feel like one elegant magazine story.

The end result should feel like a luxury editorial magazine page: calm, feminine, soft, balanced, clean and high-end — not like a menu of boxes.

## Direction to follow

### 1. Stop designing with repeated boxes
Use fewer visible containers. Avoid stacking picture boxes, quote boxes, service boxes and support boxes all in one section.

### 2. Create magazine-style sections
Each section should feel like a composed editorial spread:

- one strong image or slideshow
- one elegant heading
- one short intro
- one quote or statement in refined typography
- supporting details placed lightly underneath or hidden in read-more

### 3. Use asymmetry, but keep balance
The page can be asymmetrical, but it still needs to feel balanced. If one side has a large image, the other side should have calm copy. If there are two smaller images, they should feel intentionally placed — not like random boxes.

### 4. Use photography as part of the story
Images should not just sit above or below the copy. They should help tell the story:

- Sanchia working behind the chair
- quiet Stā Studios details
- hands applying colour or treatment
- perm rods / lotion / product detail
- finished soft movement
- calm salon moments

### 5. Keep detailed information, but hide the weight
The website still needs to educate guests, but detailed explanations should not dominate the first visual impression. Use:

- shorter visible text
- read-more sections
- slim notes
- fine dividers
- small supporting captions

### 6. Typography should lead the luxury feeling
Use the elegant display font for key headings and statements. Avoid heavy bold headings that make the page feel clunky. Dark green text should be richer and more visible, but still part of the palette.

### 7. Services section needs a rethink too
The service overview currently feels too boxy. It should not look like twelve equal blocks fighting for attention. It needs a clearer editorial hierarchy, such as:

- featured main pathways
- smaller supporting services
- read-more details
- softer dividers rather than heavy boxes
- more breathing space

## Simple sentence Sanchia can use

“I want the website to feel like a luxury hair magazine, not a menu grid. I still need the information, but I want it arranged with beautiful image-led sections, soft spacing, elegant typography and fewer obvious boxes. The pictures and wording need to feel connected, balanced and intentional.”

## Proposed reset plan

1. Pause small box-by-box tweaks.
2. Redesign the layout system for About, Services, Colour and Texture together.
3. Create one cleaner editorial pattern and apply it consistently.
4. Use fewer boxes, more image-led storytelling and softer text panels.
5. Then put the current copy back into the new layout, cutting repetition as needed.
