# Sanchia Hair Website Diagnostic — 2026-06-26

## Status
Diagnostic only. No website edits made during this review.

## Main diagnosis
The problem is not one box, photo, or section. The problem is the overall structure and navigation hierarchy.

The current site has strong brand ingredients — luxury, wellness, organic palette, editorial type, good copy bank — but it is not yet easy enough for clients to use, especially on iPad/phone.

## Biggest issues

### 1. Navigation/header is too heavy
- On iPad the sticky top area uses too much vertical screen space.
- On phone the navigation has too many links visible at once.
- The user cannot immediately see enough of each page/section.
- There are too many choices in the first navigation view.

Recommended fix:
- Use a simpler sticky header after scroll:
  - logo
  - Book / WhatsApp
  - Menu button
- Put the full list of pages inside an opened menu or section drawer.
- Keep the black 7am strip only as a homepage/top message or make it collapsible.

### 2. Too much information is visible at once
- The copy is useful, but too much of it appears upfront.
- Services and policy notes feel heavy when all shown together.
- The site needs short elegant entry points with deeper detail hidden behind read more.

Recommended fix:
- Each section should have:
  - one strong visual/editorial moment
  - one short headline
  - one short intro
  - optional read-more area for detailed explanation

### 3. Services need to become pathways, not a menu wall
Current service area explains a lot, but it asks the client to understand salon categories too early.

Recommended visible pathways:
- I need help choosing
- Colour / highlights / grey blending
- Curls / texture / modern perming
- Smoothing / QiQi
- Hair health / treatments
- Head Spa
- Visit / book

Detailed individual services can sit behind read more.

### 4. Visual direction should be soft organic editorial wellness
Best reference direction from Sanchia’s screenshots:
- warm earthy wellness layouts
- soft editorial spa templates
- large calm image areas
- green bands
- centred or layered content cards
- two-column image/text rhythm
- short visible copy with deeper panels

Avoid:
- busy yoga club styling as a whole-site direction
- dark salon styling as the whole site
- repeated equal boxes everywhere
- too many visible text cards at once

### 5. Finish strategy
Do not keep patching the current live page.

Use template-first process:
1. Build blank template for Home/hero.
2. Build blank template for About Sanchia / Meet Sanchia.
3. Build blank template for Services pathway page.
4. Build blank template for Colour.
5. Build blank template for Texture/Curls/Perming.
6. Build blank template for Hair Health/QiQi.
7. Build blank template for Head Spa.
8. Build blank template for Visit/Book.
9. Once approved, import real copy and real photos one section at a time.

## Keep
- Organic/luxury/wellness brand direction.
- Soft sage/cream/black palette.
- Editorial typography.
- 7am City appointment message.
- Health-led, bespoke, sustainable/organic/vegan-friendly copy direction.
- Read-more detail structure.

## Change
- Navigation/header behaviour.
- Services information architecture.
- Amount of visible copy per screen.
- Template rhythm and section hierarchy.
- Mobile/iPad spacing.

## Next recommended action
Create a blank navigation/header template first, because the header affects every page and is one of the biggest user-experience problems.

No real website edits until Sanchia approves the template.
